# Evidencias SQL

En esta carpeta se almacenan las evidencias de las consultas SQL realizadas sobre la base de datos Neptuno.

Las evidencias se organizan por tipo de consulta, por ejemplo:

- SQL-01-SELECT
- SQL-02-WHERE
- SQL-03-ORDER-BY
- SQL-04-LIKE
- SQL-05-COUNT
- SQL-06-AGREGADAS
- SQL-07-JOIN
- SQL-08-GROUP-BY
- SQL-09-HAVING
- SQL-10-IS-NULL
