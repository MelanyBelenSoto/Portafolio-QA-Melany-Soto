# SQL-02 - WHERE

## Objetivo
Filtrar registros específicos de la tabla clientes utilizando la cláusula WHERE.

## Consulta 1 - Ciudad

SELECT *
FROM clientes
WHERE Ciudad = 'Rio de Janeiro';

## Consulta 2 - País Brasil

SELECT *
FROM clientes
WHERE Pais = 'Brasil';

## Consulta 3 - País Argentina

SELECT *
FROM clientes
WHERE Pais = 'Argentina';

## Resultado
Las consultas se ejecutaron correctamente y mostraron únicamente los registros que cumplen cada condición.
