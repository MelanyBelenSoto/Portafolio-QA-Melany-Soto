# SQL-05 - COUNT

## Objetivo

Contar la cantidad de registros almacenados en diferentes tablas utilizando la función COUNT.

## Consulta 1 - Total de clientes

SELECT COUNT(*) AS TotalClientes
FROM clientes;

## Consulta 2 - Total de productos

SELECT COUNT(*) AS TotalProductos
FROM productos;


## Consulta 3 - Total de pedidos

SELECT COUNT(*) AS TotalPedidos
FROM pedidos;


## Resultado

Las consultas se ejecutaron correctamente y permitieron obtener la cantidad total de registros de cada tabla
