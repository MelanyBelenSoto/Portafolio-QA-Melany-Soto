# SQL-01 - SELECT

## Objetivo
Consultar registros completos de distintas tablas de la base de datos Neptuno.

## Consulta 1 - Clientes

SELECT *
FROM clientes;

## Consulta 2 - Empleados

SELECT *
FROM empleados;

## Consulta 3 - Productos

SELECT *
FROM productos;

## Resultado
Las consultas se ejecutaron correctamente y mostraron los registros almacenados en cada tabla.
