# SQL

En esta carpeta documento consultas SQL realizadas como práctica de QA para validación de datos.

## Herramienta utilizada

- MySQL Workbench

## Base de datos utilizada

Base de datos de práctica: Neptuno

### Tablas principales utilizadas

- clientes
- productos
- pedidos
- detalles_pedidos
- categorias
- proveedores
- empleados
- transportistas

## Consultas incluidas

- SELECT
- WHERE
- ORDER BY
- LIKE
- COUNT
- SUM
- AVG
- MIN
- MAX
- JOIN
- GROUP BY
- HAVING
- IS NULL

## Objetivo

Utilizar SQL para consultar y validar información almacenada en la base de datos, comprobar registros, aplicar filtros, realizar conteos y verificar relaciones entre tablas.

Las consultas fueron ejecutadas en MySQL Workbench utilizando la base de datos de práctica Neptuno.
